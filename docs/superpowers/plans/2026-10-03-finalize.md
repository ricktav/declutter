## Design decisions this plan fixes

| decision | choice | why |
|---|---|---|
| Task order | Deploy (Task 5) comes before the Computer Lab (Task 6) and iOS (Task 7) validation | The lab shows photo captions from the catalog row's `title`, which production does not return yet (Task 2 adds it). Both clients are validated against the live server, so it must run the final code first. |
| `items.update` with `houseId` and no `roomId` | Another house: the item moves there unplaced and its `pos` is cleared. Its own house: nothing changes (the room and `pos` stay) | Today the same-house call silently unplaces the item and the other-house call leaves a `pos` in a room frame the item has left. No current caller sends `houseId` alone (Workbench, Flow and the lab adapter always send `roomId`), so this only removes a trap. |
| `houses.reassign` merging a same-named room | Moved items keep `pos` only when the source room's plan moves over to the target; otherwise `pos` is cleared | A `pos` is in its room's frame; the target keeps its own frame unless it takes the source's plan. |
| Orphan files | One helper, `withNewFile(file, write)`, deletes the file when the row write throws; `inbox.acceptMany` deletes its copies when its transaction rolls back | Every create path wrote the file first and left it behind on a failed insert. |
| `photos.ensureForCapture` | A transaction that locks the capture row (`SELECT … FOR UPDATE`), then finds or creates; the copy keeps the capture's real MIME type | Two taps on the same inbox photo made two photos; a PNG capture was recorded as `image/jpeg`. |
| Test uploads | `putFile()` reports every key it writes to the test setup, which deletes them after each test | Test runs left `<hex>-items_<id>_cutout-*.jpg` files that the row-based cleanup missed. |
| Computer Lab and the house header | The adapter sends `x-house-id` when `HOMEBASE_HOUSE_ID` is set, and passes `houseId: null` to `items.listAll` and `rooms.list` so the lab still sees every house | The header makes new rooms land in the right house and lets triage resolve rooms; the lab view itself spans houses. |
| Computer Lab and the deprecated aliases | The adapter moves from `attachments.*` to `photos.*` (`photos.listAll`, `photos.add`, `photos.unlink`, `photos.listForItem`), with a fallback to `attachments.listAllImages` for an older build | The aliases are "kept for one release" (AGENTS.md §2). |
| iOS `Place` | `Place { roomId, houseId, floor, room }`: `roomId` is the truth, the other three are display copies from `rooms.list`; a place stored before this change has no `roomId` and loads as "no place" | Matches Flow's `Place = { roomId }` while keeping every label call site unchanged. |
| iOS house | Settings stores a house choice and the client sends it as `x-house-id`; lists are then scoped to that house like web Flow's switcher; `rooms.list` is always asked for every house | Same session-house semantics as the web clients. |

## Review Focus

1. **A client moves a Thing by house only** (`items.update({ id, houseId })`, the shape the old iOS build and a careless script send). Expected: into another house it lands unplaced with no leftover position; in its own house nothing changes. 2. **Two taps on the same inbox photo** (Photos tile and Inbox "Pin" both call `photos.ensureForCapture`). Expected: one photo, both callers get its id. Pinned by Task 2 test "two calls at once make one photo".

4. **Filing a brand-new Thing from the iPhone.** The server requires `itemId` to be present and `null`; Swift's synthesized `Encodable` leaves a nil out. Expected: "File it" creates the Thing in the chosen room. Pinned by Task 7 checklist step W3 and its `items.listAll` read-back.
5. **The Computer Lab started with `HOMEBASE_HOUSE_ID` set while computers live in two houses.** Expected: every computer still listed, new rooms land in that house. Pinned by Task 6 smoke check `computers-match`, which compares the adapter's list with `items.listAll({ houseId: null })`, run with the house id set.

// api/test/uploads-cleanup.test.ts
import fs from "fs";
import { describe, expect, it } from "vitest";
import { putFile, withNewFile } from "../lib/filestore";
import { keyPath, trackedUploads } from "./fixtures";

// No afterEach here on purpose: api/test/setup.ts must clean up by itself.
let written = "";

describe("files the app writes during a test", () => {
  it("are tracked as they are written", async () => {
    written = (await putFile({ bytes: new Uint8Array([1, 2, 3]), fileName: "items/1/cutout-1.jpg" })).key;
    expect(trackedUploads()).toContain(written);
    expect(fs.existsSync(keyPath(written))).toBe(true);
  });

  it("are gone before the next test starts", () => {
    expect(written).not.toBe("");
    expect(fs.existsSync(keyPath(written))).toBe(false);
  });
});

describe("withNewFile", () => {
  it("deletes the new file when the row write throws", async () => {
    let key = "";
    await expect(
      withNewFile({ bytes: new Uint8Array([1, 2, 3]), fileName: "items/9/cutout-x.jpg" }, async (saved) => {
        key = saved.key;
        throw new Error("insert failed");
      }),
    ).rejects.toThrow("insert failed");
    expect(key).not.toBe("");

import Foundation

/// Place <-> a UserDefaults dictionary. A place saved before rooms had ids has
/// no `roomId`, so it loads as "no place" and the room is picked once more.
enum PlaceCoding {
    static func row(_ place: Place) -> [String: Any] {
        var row: [String: Any] = ["floor": place.floor, "room": place.room]
        if let id = place.roomId { row["roomId"] = id }
        if let id = place.houseId { row["houseId"] = id }
        return row
    }

    static func place(_ row: [String: Any]) -> Place {
        guard let roomId = row["roomId"] as? Int else { return .empty }
        return Place(
            roomId: roomId,
            houseId: row["houseId"] as? Int,
            floor: row["floor"] as? String ?? "",
            room: row["room"] as? String ?? ""
        )
    }
}

/// Device-only default Place for a capture, matching `flow.snapPlace` in `src/flow/data.ts`.
enum SnapPlaceStore {
    private static let key = "flow.snapPlace"

    static func get(_ captureId: Int) -> Place? {
        guard let raw = UserDefaults.standard.dictionary(forKey: key) as? [String: [String: Any]],
              let row = raw[String(captureId)]
        else { return nil }
        let place = PlaceCoding.place(row)
        return place.hasRoom ? place : nil
    }

    static func set(_ captureId: Int, place: Place) {
        var all = UserDefaults.standard.dictionary(forKey: key) as? [String: [String: Any]] ?? [:]
        all[String(captureId)] = PlaceCoding.row(place)
        UserDefaults.standard.set(all, forKey: key)
    }
}

enum HereStore {
    private static let key = "declutter.lastLocation"

    static func load() -> Place {
        guard let raw = UserDefaults.standard.dictionary(forKey: key) else { return .empty }
        return PlaceCoding.place(raw)
    }

    static func save(_ place: Place) {
        UserDefaults.standard.set(PlaceCoding.row(place), forKey: key)
    }
